# Dotasys 📦💻
> **Aplicación Web para la Gestión y Automatización de Inventarios de Dotación Empresarial y EPP.**

Dotasys es una solución tecnológica desarrollada de forma autónoma para resolver un problema crítico en la administración de almacenes: el control manual, ineficiente y propenso a pérdidas de la dotación empresarial y los Elementos de Protección Personal (EPP). 

Combinando más de 20 años de experiencia real en el sector logístico con el desarrollo de software, esta herramienta optimiza las entregas, audita el stock y sistematiza el control de tallas por empleado.

---

## 🛠️ Tecnologías Utilizadas

El proyecto está construido bajo una arquitectura cliente-servidor robusta, moderna y escalable:

*   **Backend:** Python con el micro-framework Flask.
*   **Base de Datos:** MySQL (Diseño relacional para la trazabilidad de inventarios).
*   **Frontend:** JavaScript, HTML5 y CSS3.

---

## 🚀 Características Principales (En Desarrollo)

*   **Gestión de Empleados:** Registro de personal asociado a sus respectivas tallas de calzado, camisas y pantalones.
*   **Control de Stock Automatizado (Kardex):** Registro de entradas y salidas de mercancía en tiempo real con alertas de stock mínimo de seguridad para evitar desabastecimiento.
*   **Historial de Asignaciones:** Auditoría completa de qué elementos han sido entregados a cada colaborador, mitigando pérdidas de material.
*   **Reportes de Consumo:** Panel básico para la visualización del estado general del inventario en bodega.

## 💻 Requisitos de Instalación (Local)

Para ejecutar este proyecto en tu entorno local, asegúrate de tener instalado Python y MySQL.

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com
   ```

2. **Instalar dependencias:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configurar la Base de Datos:**
   * Importar el archivo SQL adjunto en tu servidor local de MySQL.
   * Configurar las credenciales de conexión en el archivo de entorno correspondientes.

4. **Correr la aplicación:**
   ```bash
   python app.py
   ```
